# RELAR BOOKS

Демонстрационный книжный магазин с каталогом из 12 произведений, поиском по названию и корзиной. Цены указаны в рублях и используются для демонстрации. Корзина хранится в `localStorage` браузера.

## Запуск

Откройте `index.html` в современном браузере. HTML, CSS и JavaScript подключены относительными путями. Сборка и установка зависимостей не требуются. Для файлов, открытых напрямую с диска, доступность `localStorage` зависит от браузера. На GitHub Pages корзина сохраняется при повторном открытии сайта в том же браузере.

## GitHub Pages

1. Загрузите файлы проекта в корень ветки `main` своего репозитория.
2. В репозитории откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, затем укажите `main` и `/ (root)` и сохраните.
4. После публикации откройте ссылку, которая появится в разделе **Pages**.

## Файлы

- `index.html` — разметка и шаблоны каталога и корзины.
- `style.css` — адаптивная вёрстка, оформление и локальные CSS-обложки.
- `script.js` — каталог, поиск, подсчёт суммы и сохранение корзины.
- `hero.jpg` — изображение для баннера.
